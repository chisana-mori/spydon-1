# Golang Lint 规范文档

## 概述

本项目使用 `golangci-lint` 作为代码质量检查工具。该工具集成了多个 Go linter，提供全面的代码质量检查。

## 安装

```bash
# 安装 golangci-lint
go install github.com/golangci/golangci-lint/cmd/golangci-lint@latest

# 或者通过 brew 安装 (macOS)
brew install golangci-lint

# 或者通过 curl 安装
curl -sSfL https://raw.githubusercontent.com/golangci/golangci-lint/master/install.sh | sh -s -- -b $(go env GOPATH)/bin v1.54.2
```

## 使用方法

### 基本命令

```bash
# 运行所有检查
golangci-lint run

# 运行指定文件的检查
golangci-lint run ./...

# 运行特定包的检查
golangci-lint run ./internal/api/

# 显示详细输出
golangci-lint run -v

# 只显示错误，不显示警告
golangci-lint run --max-issues-per-linter=0 --max-same-issues=0
```

### 配置文件

项目使用 `.golangci.yml` 配置文件，包含以下配置：

- **运行设置**: 超时时间、测试文件处理等
- **输出设置**: 格式化输出、排序等
- **Linter 设置**: 每个linter的具体配置
- **问题过滤**: 排除特定规则和文件

## 启用的 Linters

### 代码质量
- `errcheck` - 检查未处理的错误
- `gosec` - 安全漏洞检查
- `gocyclo` - 圈复杂度检查
- `dupl` - 代码重复检查
- `goconst` - 魔法字符串检查
- `gomnd` - 魔法数字检查

### 代码风格
- `gofmt` - 代码格式化
- `goimports` - import 语句格式化
- `gofumpt` - 严格的 gofmt
- `revive` - golint 的替代品
- `whitespace` - 空白字符检查

### 性能
- `prealloc` - 预分配slice/map优化
- `bodyclose` - HTTP响应体关闭检查
- `contextcheck` - context 使用检查
- `gochecknoinits` - 禁用init函数

### 错误处理
- `errorlint` - 错误处理最佳实践
- `nilerr` - nil错误返回检查
- `noctx` - 缺少context检查

### 其他
- `lll` - 行长度检查 (120字符)
- `misspell` - 拼写检查
- `nolintlint` - nolint注释检查
- `godot` - 注释格式检查

## 代码规范

### 命名规范
- 包名: 小写，简短，有意义
- 变量名: 驼峰命名
- 常量名: 大写，下划线分隔 (或驼峰命名)
- 函数名: 驼峰命名，导出的函数首字母大写
- 类型名: 驼峰命名，导出的类型首字母大写

### 注释规范
- 包级别必须有注释
- 导出的函数、类型、变量必须有注释
- 注释应该以名称开头
- 注释应该是完整的句子

### 错误处理规范
- 不要忽略错误
- 错误信息应该小写开头
- 使用fmt.Errorf包装错误时保持上下文

### 性能规范
- 预分配已知大小的slice/map
- 避免不必要的内存分配
- 正确关闭HTTP响应体
- 使用context传递超时和取消信号

## 常见问题及解决方案

### 1. Magic number
```go
// 错误
if count > 10 {
    // ...
}

// 正确
const MaxCount = 10
if count > MaxCount {
    // ...
}
```

### 2. 错误处理
```go
// 错误
data, _ := json.Marshal(obj)

// 正确
data, err := json.Marshal(obj)
if err != nil {
    return err
}
```

### 3. 变量命名
```go
// 错误
var a string

// 正确
var address string
```

### 4. 注释格式
```go
// 错误
//gets the user

// 正确
// GetUser retrieves a user from the database by ID.
func GetUser(id string) (*User, error) {
```

## CI/CD 集成

在GitHub Actions中使用:

```yaml
- name: Run golangci-lint
  uses: golangci/golangci-lint-action@v3
  with:
    version: latest
    working-directory: apps/backend
```

## 本地开发

### VS Code 配置
在 `.vscode/settings.json` 中添加:

```json
{
    "go.lintTool": "golangci-lint",
    "go.lintFlags": [
        "--fast"
    ]
}
```

### Git Hooks
使用 pre-commit hook:

```bash
#!/bin/sh
# .git/hooks/pre-commit
golangci-lint run
```

## 配置说明

详细配置请参考 `.golangci.yml` 文件中的注释，主要包含：

- `run`: 运行时配置
- `output`: 输出格式配置
- `linters-settings`: 各个linter的具体设置
- `linters`: 启用/禁用的linter列表
- `issues`: 问题过滤规则
- `severity`: 严重性配置
